📐 三角関数（倍角・3倍角・積和・和積）
・3倍角：$\sin 3\theta = 3\sin\theta - 4\sin^3\theta$ / $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$
・半角：$\sin^2\frac{\theta}{2} = \frac{1-\cos\theta}{2}$, $\cos^2\frac{\theta}{2} = \frac{1+\cos\theta}{2}$
・置き換え：$t = \sin\theta + \cos\theta = \sqrt{2}\sin(\theta+\frac{\pi}{4})$ のとき $-\sqrt{2} \le t \le \sqrt{2}$ と $\sin\theta\cos\theta = \frac{t^2-1}{2}$ を必ずセットで書く！
🔢 整数（不定方程式・余り・絞り込み3本柱）
① 積の形：$(x-a)(y-b) = k$ にして約数の組に落とす。
② 不等式で範囲を絞る：$x \le y \le z$ と仮定して $\frac{1}{x}+\frac{1}{y}+\frac{1}{z} \le \frac{3}{x}$ で最大値を抑える。
③ mod（余り）で矛盾を突く：平方数は $\bmod 3$ で $0,1$、$\bmod 4$ で $0,1$、$\bmod 8$ で $0,1,4$ しか取らない！
📈 通過領域・微積の即効ワザ
・逆像法：点 $(X, Y)$ を固定し、パラメータ $t$ の実数存在条件（判別式 $D \ge 0$、または定義域付き2次方程式の解の配置）に言い換える。
・1/6公式：$\int_\alpha^\beta (x-\alpha)(x-\beta)\,dx = -\frac{1}{6}(\beta-\alpha)^3$
・3次関数と接線（1/12公式）：$S = \frac{|a|}{12}(\beta-\alpha)^4$
